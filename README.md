# АТИ — юридические решения для бизнеса

Пробная версия сайта на React. Публикация: GitHub Pages, ветка `main`, папка `/(root)`.

- `index.html` — готовый сайт со встроенными стилями и JavaScript.
- `ATI_React_source.zip` — исходники React и инструкции для сборки и обновления.

В тестовой версии формы не отправляют и не сохраняют заявки. Контакты, политика обработки персональных данных и образец отчёта демонстрационные.

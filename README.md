# АТИ — сайт юридических услуг

Опубликован: https://illik5b-hue.github.io/ati-test/

React 18, React Router 6 и Vite 6. Четыре страницы услуг имеют собственные URL, заголовки, описания и предварительно отрисованный HTML. Старые ссылки с `#/analysis`, `#/services` и `#/recovery` перенаправляются на соответствующие страницы.

## Сборка

```sh
npm ci
npm run build
```

Содержимое `publish/` загружается в корень ветки `main`, из которой GitHub Pages публикует сайт. JavaScript и CSS встроены в каждый HTML; PDF, изображения страниц отчёта и favicon лежат рядом. `ATI_React_source.zip` содержит исходники, конфигурацию и материалы для воспроизводимой сборки.

## Отчёт

`public/ATI_Primer_Pravovogo_Analiza.pdf` — четырёхстраничный демонстрационный образец структуры правового анализа. Это не отчёт о реальном должнике. Просмотрщик показывает изображения, отрисованные из этого же PDF, и позволяет скачать оригинал.

Для повторного создания PDF нужны Python, ReportLab и шрифты DejaVu Sans. Затем страницы отрисовываются Poppler `pdftoppm` в JPG 794 × 1123.

## Подключение заявок

В `src/site-config.js` необходимо заполнить подтверждённые контактные данные, наименование оператора, ИНН, тексты политики и согласия, а также HTTPS-адрес обработчика. После согласования документов установить `privacyApproved: true`.

Пока эти сведения не заполнены, приём заявок отключён и сайт сообщает об этом посетителю. Каждая форма содержит две отдельные обязательные галочки, по умолчанию снятые. Успех показывается только после ответа обработчика с успешным HTTP-статусом и JSON `{ "ok": true }`.

Обработчик должен принимать POST JSON: `service`, `name`, `phone`, `details`, `consent`, `policy`, `consentVersion`. Он должен проверять данные и оба согласия на сервере, ограничивать частоту запросов и разрешать CORS для опубликованного сайта. Секреты и почтовые пароли в клиентский код не добавляются.

## Подготовка к продвижению

Добавлены отдельные URL, метатеги, canonical, Open Graph, sitemap.xml и предварительно отрисованный текст. Регистрация в кабинетах поисковых систем, аналитика и рекламные кампании ещё не настроены.
